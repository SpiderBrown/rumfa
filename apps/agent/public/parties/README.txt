Party logos for the live count buttons.

Add one image per party on the ballot, named by the lower-case party code:
  apc.png, pdp.png, lp.png, nnpp.png, ...

Square images about 128 x 128 pixels work best (PNG with a transparent or white background).
Use the official logos as registered with INEC. A party without a file shows its code only.
The path pattern is set by partyLogos in public/config.js.
